# 项目大纲：多用户、多级目录结构文件系统设计与实现

## 一、项目目标与概述

**核心目标**：模拟UNIX文件系统操作，实现一个支持多用户、多级目录结构的命令行（或简单GUI）文件系统。

**功能要点**：
- 文件系统的格式化与初始化
- 多用户管理（用户创建、登录、权限控制）
- 多级目录结构（树形目录）
- 文件与目录的创建、删除、读写操作
- 目录的切换、列表显示
- 文件内容的持久化存储

## 三、核心数据结构设计

### 1. 超级块 (SuperBlock)
- 文件系统总大小
- 空闲块数量与位图位置
- inode 区位置与大小
- 根目录 inode 号

### 2. inode 结构
```cpp
struct INode {
    int i_id;              // inode 编号
    int i_type;            // 文件类型：文件/目录
    int i_size;            // 文件大小
    int i_blocks;          // 占用块数
    int i_uid;             // 所有者用户ID
    time_t i_atime;        // 访问时间
    time_t i_mtime;        // 修改时间
    int i_block[10];       // 直接/间接块指针
};
```

### 3. 目录项结构
```cpp
struct DirEntry {
    int d_ino;             // inode 编号
    char d_name[28];       // 文件/目录名
};
```

### 4. 用户结构
```cpp
struct User {
    int u_id;
    char u_name[32];
    char u_password[64];   // 简单加密
    int u_home_dir;        // 主目录 inode
};
```

## 六、数据持久化方案

**方案**：使用单一磁盘镜像文件（`filesystem.img`）

```
+------------------+
|    SuperBlock    |  块 0
+------------------+
|   inode Bitmap   |  块 1
+------------------+
|   block Bitmap   |  块 2
+------------------+
|    inode 区      |  块 3 ~ 块 18 (16 个 inode)
+------------------+
|    数据块区      |  块 19 ~ 最后
+------------------+
```

- 块大小：512 字节
- inode 数量：可配置（如 128）
- 文件系统总大小：可配置（如 10MB）
